# AutoShield 智驾 UBI 比赛演示网站

当前模型：L1L2L3-1.0.0，2026年11月14日。唯一产品依据为项目根目录《AutoShield商业计划书_最小修订版.docx》。本轮没有修改商业计划书。

## 打开网站

双击同目录的 `index.html`，使用 Windows Chrome 或 Edge 打开。只需保留 `index.html`、`style.css`、`model.js`、`script.js`、`presentation.js` 五个文件在同一文件夹；README供阅读。

原生HTML/CSS/JavaScript，无需安装Node、npm、后端、数据库或API Key。无CDN、在线字体、远程图片、联网请求或本地fetch；无网络也能完成核心演示。不采集个人身份、真实车辆或驾驶数据，不在浏览器中持久化输入。

所有结果均为比赛模拟演示，非实际保险报价。AutoShield是保险科技定价与数据服务方案，不是持牌保险公司。

## 五步路演

点击顶部“开始演示”：传统定价问题 → 输入车辆与驾驶参数 → 计算UBI模拟保费 → 解释差异 → 展示创新与边界。

使用“下一步”“上一步”，或在非输入控件上按左右箭头。点击“全屏展示”进入浏览器全屏，再点一次退出；若浏览器禁止全屏可用F11。“退出演示”返回完整网页。Esc可退出路演；处于浏览器全屏时可先退出全屏。

“重置参数”恢复普通驾驶场景、主测算、独立情景快照及经营假设；路演中的重置同时回到第一步。默认L1=3000、智驾比例60%、接管中位数5.5秒、脱手15%、急行为4次/月、L3=1，得分50、L2=1、最终3000元。

四组虚构场景按钮载入原始指标，由同一引擎计算：低行为风险2565元、普通3000元、高行为风险3300元、未授权3000元。前三组智驾比例均60%，差异来自行为指标与明确选择的L3假设，不是“多用智驾固定降价”。

## 唯一计算公式

`P = L1 × L2 × L3`

按计划书第2.8节与第3.2节：

- R1 = (t_med − 1) ÷ 9 × 100；t_med是近30次接管反应中位数，清洗后1–10秒。
- R2 = min(脱手占比 ÷ 30% × 100, 100)。页面输入百分数，代码用`handsOffPercent/30*100`，等价于先将两项百分数换为小数再相除。
- R3 = min(急驾驶行为月频次 ÷ 8 × 100, 100)。不改为每公里事件数。
- R = 0.40R1 + 0.35R2 + 0.25R3。
- s = clip(100 − R, 0, 100)。
- L2 = k = clip(1.10 − 0.002s, 0.90, 1.10)。
- L3：完整且上报可靠时，手动选择0.95–1.00的演示参数；没有完整率自动映射。

权重、阈值、系数区间和线性映射均为待实证验证的演示假设。智驾使用比例仅描述使用程度/暴露分层，不参与R、s或k，不另加第四因子。车型与年里程描述L1比较条件，不重复叠乘系数。

L2的±10%限制只约束L2。L3叠乘后，最低组合为0.90×0.95=0.855，即14.5%演示折扣，最终保费并非绝对限制于±10%。

## 数据与输入处理

- 未授权、撤回授权、严重不足：不读取行为统计量，不生成个人评分，L2=L3=1，P=L1。
- 部分缺失但仍可评分：按有效统计量算L2，L3强制为1，不因缺失额外加价。
- 完整且可靠：L2由行为计算，L3由演示者选择；相关优惠不是已经验证的数据奖励。
- 沿用原稿近30次接管观察、关键单字段缺失率>20%不评分的演示口径，非验证过的可靠性阈值；记录须可核验、时长分母>0、三项统计量可计算。核验选项可在“有效统计量核验与缺失处理”展开。
- 声称完整但输入缺失率>0时，安全转为部分缺失，L3=1，并提示原因；缺失率>20%则停止评分回L1。
- 接管时长>10秒清洗截为10秒并提示。脱手>100%、负数、非有限值、错误系数等提示并暂停计算；缺少必要统计量或分母无效则不评分回L1，不伪造低风险。
- L1必须为1–100000元且精确到分；其余输入规模上限是演示输入防误操作边界，不是新的定价风险阈值。中间量保持完整精度计算，最终金额按分舍入。

## 独立精算情景

网页3,000元是独立设定的交互演示基准。第3.1节另组原参数：Σwλμ=0.55×0.50×40000+0.25×0.36×47000+0.20×0.20×42000=16910元/年；组合条件案均=16910/0.405=41753.09元/件；技术保费=16910/75%=22546.67元。不能与3,000元混为同一产品真实费率。

经营说明中预期赔款默认2250元、费用率25%也是独立演示假设。赔付率=预期赔款/模拟保费，综合成本率=赔付率+费用率（简化同口径）。改变保费不会自动改变赔款，75%不是系统保证达到的成果，真实定价和经营效果须用合法理赔与暴露数据校准。

网站不把模拟档位不一致率当真实错判率，无承保、投保、购买、支付、定责、自动免赔或自动拒赔功能。定价层L2/L3与驾驶自动化等级L2/L3不同。
