# AutoShield 90秒网站演示脚本

开始前：双击项目目录的 `index.html`，保持默认普通风险场景，点击“开始演示”；投影可点击“全屏展示”。四组均为虚构样例。

| 时间与路演步骤 | 操作 | 讲稿 |
| --- | --- | --- |
| 0–15秒：传统定价问题 | 展示第一步，点击“下一步” | 各位评委，AutoShield关注一个问题：同样的车型、同样的智驾使用比例，接管和脱手表现可能不同。我们在传统基准之上，探索行为变量的定价价值，而不是多用智驾就自动打折。 |
| 15–30秒：输入参数 | 第二步显示默认普通场景，指出接管、脱手、急行为三项；下一步 | 网页基准3,000元是独立交互演示假设。行为评分只采用计划书的三项公式，权重为40%、35%、25%；智驾占比60%只描述使用程度，不直接调价。 |
| 30–55秒：计算保费 | 第三步依次点击A、B、C、D四组场景 | 相同智驾占比下，规范场景得分100，行为系数0.90，叠加假设数据系数0.95，模拟保费2,565元；普通场景是3,000元；高行为风险场景是3,300元。切换未授权，不生成个人评分，两个系数回到1，恢复基准。 |
| 55–75秒：解释差异 | 切回A，再点下一步显示L1/L2/L3桥图 | 最终保费等于L1乘L2乘L3。部分缺失但可评分时，L3固定为1，不因缺失额外加价；完整数据的0.95至1.00只是可选演示假设。±10%约束的是L2，叠乘后的总折扣可以超过10%。 |
| 75–90秒：创新与边界 | 下一步显示第五步 | 我们的创新是行为可解释、授权规则透明、与传统基准兼容。团队提供定价与数据服务，由持牌险企负责真实承保理赔。所有结果均为比赛模拟，不能证明自动达到75%赔付率，真实效果仍需理赔数据验证。 |

备用回答：计划书16,910元纯风险保费、22,546.67元技术保费属于另一组参数的精算情景，不能与网页3,000元交互基准混用。未授权回归基准不表示已判断其真实风险水平。

操作备用：上一页返回解释；“重置参数”恢复普通风险、3,000元默认场景；“退出演示”返回原网页。全屏若被浏览器限制，可使用F11，核心计算不依赖全屏或网络。
